# Sentiment Analysis on Customer Feedback (NLP)

Automatically classifying customer reviews as Positive, Negative, or Neutral — giving product and support teams fast, scalable visibility into customer sentiment instead of manually reading thousands of reviews.

## Problem
Manually reading every customer review doesn't scale. This project builds a text classification pipeline that tags feedback by sentiment automatically, so teams can triage negative feedback first and track sentiment trends over time.

## Approach
1. **Text cleaning** — lowercase, strip punctuation/numbers, normalize whitespace
2. **TF-IDF vectorization** (unigrams + bigrams) — turns text into numerical features weighted by word distinctiveness
3. **Modeling** — trained and compared Multinomial Naive Bayes (classic text baseline) vs Logistic Regression
4. **Evaluation** — macro-averaged Precision, Recall, F1 (fair across all 3 classes, not skewed by class size)
5. **Interpretability** — extracted the top words driving each sentiment class from model coefficients

## Results

| Model | Accuracy | Precision (macro) | Recall (macro) | F1 (macro) |
|---|---|---|---|---|
| Multinomial Naive Bayes | 94.9% | 94.9% | 94.7% | 94.8% |
| **Logistic Regression** | **95.5%** | 95.4% | 95.3% | 95.4% |

Most misclassifications happen around the **Neutral** class — expected, since mixed-sentiment reviews are genuinely ambiguous even for human readers, not just models.

## Tech Stack
Python · Pandas · NumPy · Scikit-learn (TF-IDF, Naive Bayes, Logistic Regression) · Matplotlib · Seaborn

*Chose scikit-learn's `TfidfVectorizer` over NLTK for a leaner, production-friendly pipeline with fewer dependencies.*
